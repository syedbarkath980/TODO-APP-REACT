Todo (Context + LocalStorage)

This is a small Todo application built with React and Vite. The main purpose of this project is to strengthen basic React skills. The app is intentionally simple so I can focus on core concepts.

Features

- Add, delete todo items
- Check and uncheck items as completed or not.

Technologies

- React
- Vite
- JavaScript (ES2020+)

Future Improvements

- Edit existing todo items
- Persist todos using localStorage
- Style completed items with a strikethrough
- Use React Context (`useContext`) for state management
